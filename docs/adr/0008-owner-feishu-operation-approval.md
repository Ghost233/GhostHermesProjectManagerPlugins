# 本人在 Lark 答复原 DSH 操作审批

2026-10-10，用户确认由 Hermes 主插件接收本人的“批准一次”或“拒绝”，再答复同一原 DSH 审批。本人必须引用对应通知，或提供唯一审批编号。原待决状态和完整操作材料决定答复是否有效。

用户希望在 Lark 处理具体操作，同时让后台保持无界面运行。此决定替代 [ADR 0004](0004-feishu-questions-and-native-approvals.md) 中执行审批只能在原生界面处理的规则，原决定保留为历史。普通问答、规划确认和普通“同意”仍不能批准操作。

单次允许保持既有工具、仓库和沙箱范围。插件先核对原审计，再处理重复或未知结果，并分别汇报审批决定和实际工具结果。原 SDK、认证组件、认证链接发布文件、导入器和模型可见审批工具保持既有边界。
