# 飞书问答与原生执行审批

2026-10-10，用户确认每轮问题用一条飞书消息呈现。用户引用回复题号或自由文本，普通问题和规划确认送回原 DSH 任务，继续同一工作流程。具体执行审批在本机 DSH 原生界面处理，避免将规划确认当作运行命令或增加权限的许可。

当前收件校验要求真实 @。首版提问须提示用户引用本轮消息，并通过平台选择器 @ 发问机器人，沿用现有收件权限。引用与 @ 的真实事件以及原任务关联仍须实测。

用户确认同一轮问题可以分次回答。负责人记录已答和待答项，收齐本轮答复后整轮送回 DSH。明确跳过或交给 DSH 决定时，记录用户的原答复；未答题目保持待答，不自动视为同意。

首版须验证多轮问题、多个问题、分次收集、超时后续答，以及审批通知、原生界面可达性和结果回流。现有单问题入口或源码中的接口不能作为这些场景已通过的证据。
