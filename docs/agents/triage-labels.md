# 分类标签

| 规范角色 | 当前 tracker 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 维护者需要评估此 issue |
| needs-info | needs-info | 等待报告者补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交给代理处理 |
| ready-for-human | ready-for-human | 需要人类实施 |
| wontfix | wontfix | 不会处理 |

Wayfinder 使用独立的 wayfinder:map、wayfinder:research、wayfinder:prototype、wayfinder:grilling、wayfinder:task 标签；这些标签不表示可直接实现。
